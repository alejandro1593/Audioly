# PLAN FRONTEND - AUDIOLY (NEXT.JS)

## 1. TECNOLOGÍA PRINCIPAL
- **Framework**: Next.js 14 (App Router)
- **Lenguaje**: JavaScript/TypeScript
- **Estilos**: Tailwind CSS
- **Estado**: Zustand
- **HTTP Client**: Axios

## 3. COMPONENTES PRINCIPALES


#### Player.jsx (Fixed Bottom)
```javascript
- Ahora sonando (cover, title, artist, like)
- Controles (prev, play/pause, next, shuffle, repeat)
- Barra de progreso (seekable)
- Volumen (slider + mute)
- Cola de reproducción
```

#### Navbar.jsx

## 5. HOOKS PERSONALIZADOS

### usePlayer.js
```javascript
// Hook principal del reproductor
- currentSong
- isPlaying
- volume
- progress
- duration
- queue
- shuffle
- repeat
- play(song)
- pause()
- next()
- previous()
- seek(time)
- setVolume(vol)
- toggleShuffle()
- toggleRepeat()
- addToQueue(song)
- removeFromQueue(index)
```

### useAuth.js
```javascript
// Hook de autenticación
- user
- isAuthenticated
- login(email, password)
- register(data)
- logout()
- updateProfile(data)
```

### useDebounce.js
```javascript
// Hook para búsquedas en tiempo real
- Debounced value (300ms delay)
- Evita múltiples llamadas a la API
```

## 6. STORES (ZUSTAND)

### usePlayerStore.js
```javascript
- State: currentSong, isPlaying, volume, progress, queue, shuffle, repeat
- Actions: play, pause, next, previous, seek, setVolume, addToQueue
- Persist: guarda en localStorage para mantener estado al recargar
```

### useAuthStore.js
```javascript
- State: user, token, isAuthenticated
- Actions: login, logout, setUser, refreshToken
- Persist: token en localStorage/cookie
```

### useLibraryStore.js
```javascript
- State: playlists, likedSongs, history
- Actions: fetchPlaylists, toggleLike, addToHistory
```

## 7. FUNCIONALIDADES UI/UX

### Reproducción Continua
- El player NO se detiene al navegar entre páginas
- Estado persiste en todo el sitio
- Actualización de UI en tiempo real

### Atajos de Teclado
- Espacio: Play/Pause
- Flecha izquierda/derecha: Seek ±5s
- Flecha arriba/abajo: Volumen ±5%
- M: Mute
- N: Next
- P: Previous
- S: Shuffle
- R: Repeat

### Drag & Drop
- Reordenar canciones en playlists
- Añadir canciones desde la cola
- Reordenar cola de reproducción

### Virtual Scrolling
- Para listas grandes de canciones
- Carga infinita en resultados de búsqueda
- Performance óptima

### Responsive Design
- Desktop: Sidebar + Player
- Tablet: Sidebar colapsable
- Mobile: Bottom navigation + Player

### Animaciones
- Transiciones suaves entre páginas
- Hover effects en cards
- Animación de play/pause
- Progress bar animada

### Dark Mode
- Tema oscuro por defecto (como Spotify)
- Toggle para tema claro (opcional)

```javascript
// Protección de rutas
```
