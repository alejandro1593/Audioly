# PLAN FRONTEND - AUDIOLY (NEXT.JS)

## 1. TECNOLOGÍA PRINCIPAL
- **Framework**: Next.js 14 (App Router)
- **Lenguaje**: JavaScript (JSX)
- **Estilos**: Tailwind CSS (tema cyber oscuro, neon)
- **Estado**: Zustand
- **HTTP Client**: Axios (instancia con interceptor de refresh token)
- **Toast**: react-hot-toast

## 3. PÁGINAS CLAVE

### Home (app/page.js)
- Mix del día (tarjeta con enlace a `/mix`) si hay sesión
- Lo más escuchado / TRENDING (SoundHelix + éxitos Spotify)
- Álbumes destacados
- CTA de login para invitados

### Mix / Playlists automáticas (app/mix)
- Hero con el mix actual y botón **Reproducir todo**
- Toggle **Mix del día ↔ Recuerdos** (daily / flashback)
- Grilla de canciones ordenadas por afinidad

### Canción (app/song/[id])
- Reproductor embebido / stream propio
- Like, historial de reproducción
- **Letras**
- **Comentarios** (avatares de autor, borrar los propios)
- **Artistas similares** y canciones relacionadas

### Artista (app/artist/[id])
- Header con imagen y bio
- Seguir / dejar de seguir
- Canciones top (play all)
- Discografía (álbumes)
- **Artistas similares**

### Perfil de usuario (app/user/[id])
- **Avatar grande** con botón de cámara para **cambiar foto** (solo en tu propio perfil)
- Seguidores / siguiendo
- Seguir / dejar de seguir
- Playlists y "Me gusta" del usuario

### Playlist (app/playlist/[id])
- Header con portada y dueño
- Reproducir / shuffle
- Like a la playlist
- **Colaboradores** (añadir/quitar en la tuya)
- **Compartir** → copia de link público `/shared/:token`
- Reordenar canciones con drag & drop

### Recap (app/recap)
- Resumen estilo Wrapped: top canciones, artistas y álbumes del usuario
- Render con transición entre "slides"

### Ajustes (app/settings)
- Editar username, email
- **Avatar**: subir imagen (FormData → POST /users/avatar), preview, o campo de URL manual
- Cambiar contraseña

### Admin / Upload
- Admin: gestión de álbumes, artistas, canciones, podcasts
- Upload: formularios multiparte con subida de imagen/audio a `/uploads`

## 4. STORES (ZUSTAND)

### useAuthStore.js
- State: user, token, isAuthenticated
- Actions: login, logout, setUser (refresca avatar tras subirlo), refreshToken
- Extras: `id`, `username`, `avatar`, `hasAvatar` derivados

### usePlayerStore.js
- State: currentSong, queue, isPlaying, volume, isShuffled, repeatMode, compact/floating mini-player
- Persist: guarda en localStorage para continuar al recargar

### useLibraryStore.js
- State: playlists, likedSongs, history, savedAlbums, followedArtists
- Actions: fetch, toggleLike, addToHistory, fetchMix

### useNotificationStore.js
- State: notifications, unreadCount
- Actions: fetch, markRead, markAllRead (apoyado por el backend)

## 5. FUNCIONALIDADES UI/UX

- **Player global**: no se detiene al navegar; mini-player flotante al hacer scroll
- **Reproducción bajo login**: hook `useRequireLoginToPlay` (dialog → login)
- **Botones de camisa/estados globales**: like, play, añadir a playlist con feedback toast
- **Avatar unificado**: `mediaUrl()` resuelve `/uploads/...` con el origen del backend (evita 404)
- **Drag & drop** para reordenar canciones de playlist
- **Responsive**: sidebar escritorio, bottom-nav móvil
- **Tema cyber**: gradientes, bordes neon, `shadow-neon`
